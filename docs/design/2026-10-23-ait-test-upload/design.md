## 목적과 현재 근거

운영 광고 ID를 연결한 수정 후보를 앱인토스 콘솔의 테스트 가능한 번들로 올린다. 제품 코드와 화면은 바꾸지 않는다. 실제 운영 ID는 GitHub `apps-in-toss` 환경의 `VITE_AIT_AD_GROUP_ID`에서 읽으며 값은 `ait.v2.live.d443768a005940c4`와 일치해야 한다.

기존 후보의 자동 검사 42개와 개발 브라우저의 퀴즈 완료 흐름은 통과했다. 중앙 `before-build` 검증은 `DEVELOPMENT_EVIDENCE_ARCHIVE_MISSING`으로 실패했다. 소스에는 승인된 테스트 계획과 기능 목록도 없어, 보관함만 생성해서 해결됐다고 처리할 수 없다.

## 테스트 계획

등급은 L1, 환경은 개발 환경이며 출시 끝 지점은 `test-track`이다. 새 화면이나 화면 개편은 없다. 코드 리뷰는 사용자의 생략 지시를 유지한다.

| 기능과 조건 | 실행할 검증 |
|---|---|
| 원소 탐색과 검색 | 118개 원소, 이름과 기호와 번호 검색, 분류 필터, 상세 진입을 검사한다. |
| 퀴즈 | 난이도별 문항 생성과 완료, 마지막 답 중복 입력 방지, 결과와 다시 풀기를 확인한다. |
| 광고 | SDK 대체 구현으로 로드 완료 전 표시 금지, 동일 ID 표시, 로드 실패와 취소와 5초 대기 만료, 정상 닫힘과 닫힘 알림 유실 시 120초 상한을 검사한다. |
| 광고 설정 | 운영 빌드의 ID 누락과 테스트 ID 거부, 실제 ID 주입, 개발 빌드의 테스트 ID 허용을 확인한다. |
| 이동과 저장과 계측 | 뒤로 가기와 중단 취소, 최근 원소 저장과 복원, 퀴즈 완료와 광고 노출 이벤트의 중복 방지를 확인한다. |
| 실제 개발 화면 | 별도 Edge 세션의 격리 저장소에서 원소 탐색, 검색, 퀴즈 완료, 결과와 다시 풀기, 중단 후 복귀를 실행한다. 개발 환경의 광고 미지원 처리를 확인한다. |

기능 목록 v1의 광고와 저장은 공용 `App.tsx` 경로 때문에 기기 하한이 올라간다. 이번 범위는 기존 SDK 3.5.0을 유지한 설정과 일반 흐름 복구이며, 개발 환경에서 확인한 범위만으로 테스트 업로드까지 진행하도록 `floorOverrides`를 제안한다. 실제 토스 광고 노출과 저장 SDK의 기기 실행을 통과로 기록하지 않는다. 기기를 조회하거나 실행하지 않는다.

## 실패와 운영 상태

검증기 실패, 후보 SHA 불일치, 운영 ID 불일치, 파일 해시 불일치, 서버 컴파일 실패에서는 멈추고 원인을 기록한다. 테스트가 실패하면 같은 수정 범위에서 원인을 고치고 새 후보를 검증한다.

광고 그룹은 2026-10-23 조회 기준 `PENDING_DELETION`이며 2026-10-30 삭제예정이다. 콘솔 설명상 23일 연속 노출이 없을 때 생기는 상태다. 업로드 성공을 광고 노출 또는 삭제예정 해제로 보고하지 않는다.

현재 공개 버전 `20260926-10`을 유지한다. 실패한 테스트 번들은 공개하지 않는다. 검수 원본과 번들은 NAS1dual에 스트림 복사하고 크기와 SHA-256을 대조한 뒤 임시 파일을 정리한다.
